# 0.7 · A button, and a world behind it

## 为什么 0.6 显得安静

主视觉主要是网络、信号和窗口的抽象符号，真正有意思的网站与新闻退到了下一层。三个空间虽然有不同控件，却共享“大标题 → 并排组件 → 同一种阅读卡”的节奏。大量留白围绕功能解释，没有为真实内容制造焦点和前后关系。

保留米白底、英文标题与中文说明、朱红路径、既有三种隐喻、内容与本地保存。此次继续使用 React / Vite / TypeScript，不改数据库、接口、内容身份或启动器。

## 新构图

首页先给一个直接的出发按钮，周围和下方是一组可点击的网站样本。它们来自现有目录，包含猫、极小的月亮、沙盒、借来的窗景与个人创作；每个窗口有自己的色彩、构图和一句具体邀请。下半页通过实际消息和档案片段展示另外两种世界，替换单纯的功能卡。

```text
             Go somewhere unexpected.
                [ Take me somewhere ↗ ]
      [网站窗口] [网站窗口] [网站窗口] [网站窗口]

      世界信号场：来源刻度 + 一则真实消息
      历史展厅：一张旧窗口 + 当年事件与去处
```

- **Elsewhere**：当前网站的预览、标题、介绍与主按钮位于网络中心。真实足迹散落在周围，未知节点可点击出发，分支参与下一站的动效。手机先看当前目的地，轨迹在下面展开，保持触控和阅读空间。
- **News Drift**：整幅世界信号场承载消息，调频尺与新闻共享一个空间。世界图只标现有发布主体的来源所在地，不根据语言或标题虚构事件地点。一次捕捉一则消息，不增加信息流。
- **Time Machine**：旧网页成为主展品，事件像时间标签，去处像展厅里的海报。三类内容沿用真实来源和日期，布局、窗口和按钮随年代变化；保持完整年份包恢复。

## 视觉与取舍

纸面 `#f5f3ec`、墨色 `#272e2b`、朱红 `#b9472d` 为全站基础；信号蓝 `#294b56`、天光 `#95bbbe`、样本黄 `#dfba5e` 用于内容。系统无衬线负责标题与正文，Georgia 只用于强调语句，等宽字体用于网址、年份和来源刻度。主按钮有明确厚度，浏览器样本轻微错位；周边保持安静。

最重要的识别元素是“一组具体互联网小世界围绕一次出发”。不采用另一组抽象大图标，也不堆叠装饰性指标和无限动画。ui-ux-pro-max 用于校核触控、焦点、对比度和响应式；其通用商品评价布局不适用，因此按本项目真实内容设计。

参考 [The Useless Web](https://theuselessweb.com/) 的单一主动作和低决策成本，保留自己的色彩、窗口与内容语境。网站预览为原创视觉示意，明确标注，不假装是目标站截图；真实名称、介绍和去向来自本地目录。

## 验收

1. 首页主按钮首屏可达，附近出现具体网站示例，示例能恢复到对应真实条目。
2. 当前网站处于网络中心，未知分支能抽取下一站，旧节点能回访；重复点击、上一站、刷新与收藏继续工作。
3. 新闻调频支持拖动与键盘，每个刻度对应真实来源，消息、来源标记与日期同步变化。
4. 历史展厅突出档案并区分事件 / 去处 / 旧网页，七年主题、真实依据和整组恢复保留。
5. 检查桌面、小屏、键盘、减少动画与安全外链；完成逻辑测试、浏览器回归、构建和真实一键启动生命周期检查。

自查后压缩了首页与年代页的说明空间，把 Elsewhere 的继续探索放到中心窗口上方，新闻调频移到消息之前；修正手机调频触控高度，年份轴使用原生滚动。网站样本、未知分支、来源选择与展厅恢复均为真实可用操作。

展厅优先将当前年份包中的档案放到主展位。保留既有的未见内容优先规则：某年的档案已经遇见、仍有未见事件时，下一包可能由事件担任主展品；不会为了布局重复插入档案或改变选择规则。手机 1999 截图使用清空测试足迹后的首次进入状态。

验证使用本机 Edge 与手机视口模拟，未在实体手机上测试。既有新闻快照仍使主 JS 约为 1.60MB（gzip 约 432KB），构建保留体积提示；本轮没有增加依赖、实时抓取、第三方截图或线上部署，也未重新核验全部外站的当前可用性。
