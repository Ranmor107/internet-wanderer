# News Drift — A world within reach

2026-10-15 · 0.8.0

## 从背景地图到接收世界

0.7 的机构地图被纸面文章覆盖，标题、长阅读区和调频尺优先占据视野。地图只是背景，点击继续漂流后直接替换内容，缺少从寻找、靠近到接收的过程。

0.8 保留原有墨蓝、暖白和编辑式文字，把正交投影地球放到页面中央。桌面使用 480～660px 高的接收空间，手机使用 370～400px 高的主视觉；来源国家、状态和主动作围绕地球排列，摘录在下方出现。

- 地球：墨蓝海面 `#203e47` / `#244650`、灰绿陆地 `#b6c8b6`、浅金信号 `#e3cf9b`、暖白纸面 `#f3f0e2`。沿用项目 serif / sans / mono 字体变量，不加载远程字体。
- 继续漂流：240ms 扫描 → 1000ms 地球转向 → 1100ms 时解锁并显现消息。地球本身始终居中，不通过整块画面跳切模拟移动。
- 在 News 模式优先随机选择不同的已知发布机构国家，再选该国家的可用来源，从现有新闻选择器抽取条目。主动调频仍对应七个真实来源。Surprise 模式的主动作继续从三类内容中随机。
- 同一国家的不同语言台以轻微转向重新捕捉，明确保留所在地；不把语言当作国家。
- 摘录先显示来源、语言、日期、标题、已有摘要及必要署名 / 许可，可直接打开原文或收藏。展开后显示完整已有摘要、原始发表时间、保存状态和来源信息；本轮不生成摘要，也不转载新闻全文。
- 快速调频取消尚未提交的选择，只提交最后一次输入。转换中锁定主按钮并保留键盘焦点；离开页面清理计时器与动画帧。
- 减少动态效果模式直接显示结果，不转动地球或扫描。信号波为有限动画；首页预览进入视野后才播放，最长 4.6 秒，不持续运行。
- 首页复用同一地球、地理标记和信号波，仍可直接进入预览新闻的准确条目。

## 地理和数据边界

只展示现有数据中发布机构的所在地：NASA / 美国，Global Voices 各语言台 / 荷兰，ECB / 德国。经纬度为国家级参考点，不是办公室地址，也不是新闻事件发生地。未知来源不显示伪造标记；页面明确标注国家示意定位。现有来源只覆盖三个发布主体，地球不暗示已接入所有国家。

地球底图来自 [Natural Earth 110m land](https://github.com/nvkelso/natural-earth-vector/blob/master/geojson/ne_110m_land.geojson)，[许可为公共领域](https://www.naturalearthdata.com/about/terms-of-use/)。2026-10-15 读取的原始 GeoJSON SHA-256：`9e0729ee253ca7d7a5c4ae9395fb1902264c5377c52e224d13dd85010e2835d9`。

`src/ui/globe/land-points.json` 是该底图的 1,875 个陆地点：纬度从 -81 至 84 每 2.5 度采样，经度步长 `2.5 / cos(latitude)`，经多边形外环 / 内洞包含判断保留陆地。运行时只加载这份本地派生数据，通过正交投影显示面向观察者的一半；不需要地图 API、WebGL、外部图片或新增依赖。点阵是概括性地理示意，不绘制国界。
