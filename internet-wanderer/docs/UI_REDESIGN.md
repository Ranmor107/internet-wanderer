# Internet Wanderer · A field guide to getting lost

## 现状与保留项

0.5.0 的首页以 hero + 三张入口卡为主，结果页共享浏览器卡片和侧栏，网站明信片、报刊刊头与年代主题已存在，但主要操作仍是同一种“换卡片”。探索过程、三种模式的区别与最近遇见的关系不够直观。

保留 React / Vite / TypeScript、HashRouter、真实内容与稳定 ID、随机去重规则、七个精选年份、来源及日期语义、本地收藏与备份、20 条最近遇见、浏览器返回恢复、内容 provider 容错和永久一键启动。此次不扩建后端或数据接口。

## 设计方向

用一张不断长出路径的旅行地图贯穿全站。暖白纸面、深墨文字、朱红定位标记；细线、空心节点、坐标式编号与大字号构成品牌。三种空间分别使用苔绿、深蓝和年代主题，但沿用同一导航、间距与操作语言。图形用本地 SVG / CSS 绘制，不加载外部字体或图片。

- **首页：三个相连的世界。** 大标题与 Surprise Me 为出发点，右侧是一幅原创探索地图：散落节点、信号圆环和历史窗口互相连接。每个区域都能进入对应体验，窄屏改为连续的探索画卷。
- **Elsewhere：一步步长出的路径。** 地图上的实心节点来自真实最近遇见，点击可回访；空心分支表示未知方向。点击 Wander / 下一站，连接线绘制、新节点落位，再显示目的地说明。地图不假装记录用户在外站的实际浏览行为。
- **News Drift：调到一个远方。** 原生 range 频率尺支持拖动、点击和方向键，刻度对应实际可用新闻来源，选择来源会从其新闻池随机抽取；下一站重新随机漂流。频段编号是界面隐喻，不伪造无线电频率或新闻事件地点。新闻阅读区保留原文、语言、媒体所在地、作者、译者与发表日期。
- **Time Machine：沿时间轨道进入窗口。** 七个可用年份始终可达，同时提供前后年份和随机年份。时间大字、层叠窗口与三份切片组成年代桌面；90 年代斜面 / 等宽、00 年代玻璃 / 圆角、10 年代轻量 / 平面。原始史料链接、事件日期与快照捕获日期均保留。
- **Surprise Me：连接三种旅程。** 继续沿用分池随机，结果采用实际内容所属空间，并提供进入完整新闻或年份体验的入口。点击后出现与本次探索相应的路径、信号或窗口反馈。

参考入口：[Neal.fun](https://neal.fun/)、[oldweb.today](https://oldweb.today/)、[Web Design Museum](https://www.webdesignmuseum.org/)、[Cloudhiker](https://cloudhiker.net/)、[Wiby](https://wiby.me/)。借鉴低门槛出发、把交互作为内容、保留年代语境的思路，不复制页面或素材。ui-ux-pro-max 的设计系统搜索用于校核层次、触控、焦点和减少动画；推荐的通用卡片 / 童趣字体不适合本项目，因此采用上述原创地图构图。

## 实现与验收

1. 视觉组件（地图、调频、时间轨道）与内容选择 / 存储分离；新增来源调频仅对本次选择缩小候选集，不修改默认随机分布。
2. 核心按钮保留稳定焦点；动画只在出发、到达和模式切换时触发，无持续粒子或装饰性循环；减少动画时直接完成状态变化。手机优先显示目的地、将旅行图放在下方，并将调频台压缩为可操作的短面板，避免阅读内容被推到屏幕之外。
3. 检查首页与三个空间的桌面 / 320、375、390、768、1024、1440px 布局，无横向溢出，主要触控目标至少 44px。
4. 验证节点回访与刷新、调频来源正确与键盘、随机漂流、年份前后切换及主题、整组恢复、收藏 / 备份、来源署名、安全外链、空状态和加载失败。
5. 完成逻辑测试、浏览器回归、真实本地渲染截图、生产构建及一键启动完整生命周期后交付。

## 本轮边界

- 地图展示最近遇见的网站节点，最多显示八个；全部足迹继续采用原有二十条上限，不建立跨设备轨迹服务。
- 调频是一种来源选择方式，按钮继续漂流会重新随机选取。来源所在地不等于新闻事件发生地，不使用虚构的地理坐标或无线电频率。
- 年代窗口是设计演绎，真实旧网页仍通过外部档案链接打开，不嵌入或复刻整站。
- 48 个网站、42 条历史切片、2,243 条新闻、76 个来源和原有稳定 ID 均保留。本轮没有新增接口、依赖、全文转载或线上部署。
- 验证使用本机 Edge 和移动视口模拟，不等同于实体手机或生产网络验证。原有新闻快照仍使主 JS 约为 1.59MB（gzip 约 430KB），构建保留大文件提示。
