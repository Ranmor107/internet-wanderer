# 首页直达与连续探索体验

2026-10-23 · 0.9.0 体验更新

## 网站样本直接打开

首页六个网站样本使用标准外链，点击 / Enter 在新标签打开真实网址。卡片附近与可访问名称明确提示新标签。Ctrl / Cmd 点击、复制链接地址等浏览器原生操作继续可用。首页不切换至站内介绍页，也不改写本机漫游记录。随机主入口继续进入漫游体验。

鼠标悬停和键盘聚焦提供一致的轻抬升与阴影，保留原有错位排布。悬停只在支持鼠标的设备上生效；减少动态效果时取消位移。手机仍横向浏览样本，键盘可以聚焦到离屏链接。

## 连续探索

- 普通换站取消原90ms等待，以180ms的小幅淡入承接新内容；年代展厅保留本身的年代动效。整页入口仅淡入，避免transform让手机固定操作栏短暂脱离视口定位。
- 地球缩放按钮与返回全球尺度采用无振荡的临界阻尼过渡。从当前画面继续运动，重复点击累积目标；拖动、滚轮、键盘和新目的地可随时接管。键盘快捷键与减少动态效果设置直接到位。画面静止后仍停止渲染，退出释放资源。
- 地区列表轻量展开；点击外部关闭。Escape优先关闭列表并回到地区按钮，再次Escape可关闭新闻并回到地球画布；无WebGL时回到地区按钮。
- 同地区换报道不重复飞行，阅读层回到新标题。键盘发起切换时，标题接续焦点；选择地区后若用户在飞行途中主动Tab移走，抵达不会抢回焦点。鼠标阅读不主动把焦点拉到标题。

## 验证边界

外链测试验证实际的新标签导航请求、准确网址、首页不跳转及漫游记录不变，并阻止真正访问第三方站点；本轮没有重新审核外站内容或宣称外站持续在线。手机操作在Edge浏览器的移动视口与触摸模拟中验证，不等同于物理手机测试。
