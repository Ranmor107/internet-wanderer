# News Drift 新闻主题筛选

2026-10-26，基于现有0.9.0地球体验增量实现。

## 使用方式

地球右上方（手机顶部）选择“新闻种类”。娱乐、军事、科技、人文、社会、环境、财经和体育各自提供主题频道，默认“全部种类”。点亮的地区、地区列表、媒体来源、同地区另篇和继续漂流均使用当前类别。

切换类别先回到探索状态，不自动打开一条消息。地球、高清纹理和相机保留，只更新符合条件的信号点；飞行途中切换不会把原先未抵达的新闻记入足迹。已关闭的信号显示保持关闭。

直接点击没有对应类别报道的国家，会提示该地区尚无已归类消息，提供其他信号和“查看全部新闻”。没有该类报道的内容源会显示空类别，停止随机选择；不会用其他类别填充结果。返回全球视角仍保留所选类别；“上一站”和足迹属于原有历史导航，重新打开页面默认全部种类。

## 数据与审核

新闻总库保持2243条。本轮从中审核237条报道，建立245个主题关联，覆盖英语、西班牙语、法语、日语、简体中文与2005—2026年。无需新增抓取即可满足本轮内容需求；新增的是这些报道按主题和地区被发现的能力。

分类是依据原始标题做的编辑归类，允许跨类；军事包括战争、军队和武装冲突相关报道，人文包括语言、历史、文化与艺术。数量是保存的报道记录数，不代表独立事件数。新闻卡片展示已审核的主题；未审核报道明确标为“主题待归类”，继续在“全部”中可读。

`data/news-topics.json`独立保存ID、原题及主题，不修改新闻原文元数据。运行时必须同时匹配ID和标题；标题变化需复核才继续进入主题频道。后续新闻刷新不会自动推断主题，新增报道仍需审核；构建检查无效类别、重复ID和标题漂移。

地区索引保留原18地区和55个关联，增加65个明确标题关联，合计120关联、115条独立报道。其中91条同时具备主题归类；其他未标地区的主题报道仍可按媒体来源阅读。地区采用国家级位置示意，不把发布机构所在地当成报道事件地，按媒体阅读时标明位置依据。

## 验收边界

新闻均来自项目现有保存版本，保留原始发表日期、作者、译者、许可和原文链接；未做实时新闻或外部网页可用性验证。浏览器验收使用Edge及手机尺寸模拟，不等同于物理手机实测。未新增依赖、账户或后端。

逻辑检查覆盖审核索引、标题一致性、跨类、未归类内容和地区覆盖；浏览器检查覆盖筛选、按来源阅读、随机漂流、取消过期结果、无消息国家、隐藏信号、键盘、手机及WebGL不可用路径。永久一键启动入口和固定地址保持原有约定。

本轮验证结果：

- `npm run build`：数据校验、TypeScript与生产构建通过。
- `npm test`：97项通过。
- 浏览器全量检查覆盖91项：90项通过，1项手机外部点击用例因新的菜单层级覆盖了原点击位置而超时。将目标改为实际露出的菜单外部区域后，最终16项相关定向复查全部通过；同时验证媒体选择框不被新闻遮住、切类后可重选同一来源。最后这次调整后未再重复全部91项。
- `npm run test:launcher`：真实双击入口、当前源码、重复启动复用、依赖变化自动重启与退出清理通过。
- 桌面1440×1050、手机390×844实际截图已检查；320px布局、减少动态效果与WebGL降级路径经浏览器检查。
