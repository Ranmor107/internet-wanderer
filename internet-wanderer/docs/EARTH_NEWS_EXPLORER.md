## 以地球作为入口

此前版本依次显示地球与新闻，地球承担说明角色。0.9 改为同一个探索视口：真实三维球体、可操纵相机、球面信号和浮动阅读层。第一次进入不自动抽取文章；首页入口以全新探索状态进入，刷新及足迹回访继续恢复已选消息。

参考 [Google Earth 的旋转 / 缩放探索逻辑](https://support.google.com/earth/answer/148186)，使用 Three.js 0.186.1 与 OrbitControls 实现本地球体。没有接入 Google 地图服务或使用其图像。材质是全球卫星影像拼接纹理，球体没有城市建筑模型或逐级卫星瓦片，近距离细节受本地影像分辨率限制。

视觉采用深空 `#080f18`、真实蓝色海洋、暖白新闻纸 `#f6f2e5` 与浅金信号 `#ead9b0`，沿用品牌衬线标题与中文说明。地球保持为画面主体，选中地区后局部边界被标出，新闻在桌面左侧 / 手机浮层打开。正文区域不再排列在地球下方。

## 操作和状态

- 鼠标 / 单指拖动直接操纵视角；滚轮 / 双指缩放。方向键旋转，`+` / `-` 缩放，`Home` 恢复全球尺度，另有可见按钮。
- 点击球面上的国家轮廓或地区信号点，按地区筛选已有新闻。国家表面由射线和实际经纬度 / 多边形包含判断确定，空白海洋不会抽取别处内容。
- 随机漂流先选择另一个可用地区，再选择该地区未读 / 非当前的报道。相机从当前位置沿球面转向，在中途略微拉远后靠近目标。抵达后才提交新闻与足迹并展开浮层。
- 拖动、缩放、返回全球或选择新目的地都可打断飞行。取消的目的地不写入足迹，旧回调不能覆盖后续选择。开启减少动态效果后直接定位并接收。
- 关闭新闻保留当前视角；返回全球关闭浮层、取消待抵达内容并恢复全景尺度。热点可以隐藏，地区列表提供键盘和触屏的另一种入口。
- 新闻浮层保留原始日期、作者、译者、许可、收藏、原文链接，以及该地区的其他报道。旧闻继续明确标注，按来源浏览仍可进入全部原有新闻库。
- 首页使用同一 Three.js 球体，支持拖动和点选预览；进入主界面的链接与拖动区分开，拖动不会意外跳转。
- Three.js 和国家几何按需加载；画布离开视野、页面隐藏或静止时停止渲染，退出时释放控制器、观察器、WebGL、纹理、材质和几何。渲染分辨率限制为设备像素比 2，首页为 1.5。
- 若 WebGL 不可用，明确提示三维显示不可用，地区列表仍可筛选阅读；不会把该回退标作成功的三维渲染。

## 地区新闻与来源边界

`data/news-geography.json` 在原新闻库上添加 18 个国家 / 地区的 55 份关联记录，涉及 54 个不同条目（美墨边境一文同时关联两国）。每个关联保存准确条目 ID 与标题，按标题中明确提到的地理关系审核。测试验证它们存在于原始快照且标题一致。多个地区的关联表示报道涉及这些地区，不声称定位了事件现场。

日本、中国、印度、肯尼亚、尼日利亚、南非、巴西、墨西哥、秘鲁、智利、乌克兰、俄罗斯、印度尼西亚、菲律宾、澳大利亚、法国、土耳其和美国各有 3～4 则关联报道。坐标为国家级参考位置。未归类国家显示空状态；未归类报道在按媒体阅读时仅使用明确标注的发布机构所在地，不把机构地址当作报道地区。

原有 2,243 条多语言新闻、真实发表时间和采集快照均未重抓取或改写；这轮没有接入实时新闻。地区索引的维护方式是追加经过审核的条目关联，而非按语言推断国家。新增来源数据后，未归类内容仍可按来源阅读。
