# Changelog

## 0.9.0 新闻分类更新 — 2026-10-26

- News Drift 增加娱乐、军事、科技、人文、社会、环境、财经、体育八类筛选；地区信号、媒体来源、同地区报道和继续漂流同步遵循所选类别。
- 从现有新闻库人工审核237条报道、245个主题关联；未归类报道仍在“全部”可见，原始日期、署名和原文入口保留。
- 18个地区的报道关联由55增至120，覆盖115条独立报道；各类别有至少5个地区可探索，新闻总库仍为2243条。
- 切换类别保留地球与当前相机，取消尚未抵达的旧结果；空地区和空类别给出明确提示，支持恢复全部、键盘操作、手机及WebGL降级。

## 0.9.0 操作体验更新 — 2026-10-23

- 首页网站示例直接在新标签打开真实外站，增加一致的鼠标 / 键盘反馈，减少动态效果时保留静态反馈。
- 地球缩放与全景返回改为可打断的平滑过渡；重复点击累积目标，直接拖动接管，键盘及减少动态效果即时响应。
- 新闻换报复位滚动，地区菜单支持Escape与外部关闭；关闭后恢复操作焦点，抵达不抢走已主动移开的焦点。
- 页面入场只淡入，修复手机固定操作栏在整页位移动画中的跳动；普通换站取消90ms等待并缩短淡入。

## 0.9.0 高清更新 — 2026-10-23

- News Drift 地球升级为本地 NASA 8K 地形与海底地形阴影图，渐进加载；较低规格设备使用4K，首页保留2K预览。
- 增加球面细分和各向异性纹理过滤，采用高粗糙度材质，收细大气边缘；保留交互、飞行和来信体验。

## 0.9.0 体验更新 — 2026-10-21

- 地球增加侧向光照与薄层大气散射；飞行根据转动角度调整时长，呈现短暂球面路径、目的地提示和抵达波纹。
- News Drift 独立使用“远方来信”阅读层，地区坐标、媒体、原始日期、署名与原文入口形成连续的接收体验；同地区换报道不重复飞行。
- 保持有限时动效、按需渲染、操作中断与减少动态效果适配；移动端使用同一视口内可滚动浮层。

## 0.9.0 — 2026-10-19

- News Drift 改为真实 WebGL 三维球体，拖动 / 单指旋转、滚轮 / 双指缩放，可点击国家表面或地区信号选择报道。
- 首次进入先探索世界，新闻以桌面侧浮卡 / 手机浮层展开；随机漂流以可中断的相机飞行到达另一地区，抵达后才记录足迹。
- 新增 18 个地区的 55 份明确标题关联（54 个不同报道）；未归类地区显示空状态，媒体所在地与报道关联地区分别标明。
- 首页复用可交互球体，拖动区和出发链接分开。来源选择、旧闻署名 / 日期、收藏、回访和刷新恢复继续保留。
- Three.js 与国界几何按需加载，卫星拼接纹理保存在本地；画面静止 / 离开视野时停帧，退出释放资源，减少动态效果时直接定位。
- 永久启动器保留，新增 Three.js 和对应开发类型。素材来源与验收见 docs/EARTH_NEWS_EXPLORER.md。

## 0.8.0 — 2026-10-15

- News Drift 改为以本地点阵地球为中心的接收界面，扫描、地球转向和国家标记锁定后显现新闻。
- 继续漂流优先切换发布机构国家，手动调频仍选择真实来源；标记不推断报道事件地点。快速切换取消未提交选择，离开页面清理动画。
- 摘录支持展开，保留原文、作者、译者、许可、真实日期与收藏。首页复用同一地球信号预览。
- 支持手机、键盘及减少动态效果；Natural Earth 公共领域底图派生为本地数据，无地图 API 和新增依赖。
- 其余两种漫游模式、内容库与永久一键启动入口保留。

## 0.7.0 — 2026-10-13

- 基于 0.6.0 深化 UI：保留暖白编辑气质，将具体内容放到视觉中心，压缩功能说明与首屏空白。
- 首页突出 Take me somewhere 主按钮；六个真实网站样本使用不同原创视觉示意，可直接进入对应条目。下方用真实新闻和历史网页意象呈现另外两种探索方式。
- Elsewhere 的网站窗口成为网络中心，四个未知分支支持鼠标和键盘出发；继续探索沿不同分支到达，真实最近遇见形成轨迹并可回访。
- News Drift 将发布机构地图、原生来源调频尺和中央纸面消息整合为世界信号场；只标机构所在地，保留原始日期、作者、译者与许可。
- Time Machine 将网页档案设为主展品，事件采用票签、去处采用海报；不同年代继续改变窗口、字体和按钮。手机年份轴横向浏览并定位当前年份，固定收藏操作对应主展品。
- 网站预览与历史网页意象均明确标注为原创示意；原站及精确档案仍通过安全外链打开。
- 保留既有数据、随机选择规则、本地收藏备份和永久一键启动；未增加依赖或后端。增加网站样本、未知分支、机构地图、年代展厅及小屏入口的浏览器回归。

## 0.6.0 — 2026-10-13

- 首页重构为三个彼此相连的探索空间，Surprise Me 为主要出发动作；采用暖白纸面、朱红路径、坐标编号与克制的节点图形。
- Elsewhere 使用真实最近遇见构建节点旅行图，可点击回访；Wander 绘制新路径并展示目的地，保留连续探索、上一站与刷新恢复。
- News Drift 增加支持拖动和键盘的来源调频尺。刻度对应实际可用来源，选择后从该来源随机抽取；继续漂流重新从新闻池抽取。阅读区保留语言、来源所在地、原始发表时间、作者、译者及许可。
- Time Machine 使用七年时间轨道、相邻年份控制与层叠档案窗口；斜面等宽、玻璃圆角、平面轻量三种年代控制字体、按钮与浏览器外框。增加可展开的历史依据入口。
- Surprise Me 沿用分池随机，以实际结果所属空间呈现，并显示三种探索方式之间的关联。
- 全站品牌、收藏弹层与 About 统一；保留本地收藏及备份、原有内容 ID、提供层容错和永久一键启动。未增加依赖、后端或数据接口。
- 动效限定在出发、到达和捕获信号，支持减少动画；窄屏保留固定的上一站、继续探索和收藏操作栏。

## 0.5.0 — 2026-10-10

- 网站池由 36 个扩大到 48 个。参考 The Useless Web 的官方入口，逐站检查并加入弹跳猫、圆点揭图、几何画、二进制钢琴、表情花园及小游戏等 12 个网站，保留原创中文介绍与操作提示。
- 新增 1996、2001、2004、2016，各有 2 个事件、2 个去处、2 份精确档案；历史切片由 18 条扩大到 42 条，年份由 3 个扩大到 7 个。
- 核验八份 Wayback 回放的 HTML、原网址和实际捕获时间。区分事件发生、公开宣布、现行作品资料、保留旧站与真正的网页快照；来源和边界见本轮核验记录。
- 年份导航自动换行，支持小屏完整查看所有年份。扩展配置即可复用既有年代主题；保留当前选择、整组返回与档案收藏恢复。
- 构建校验增加每年三类切片齐全、全部历史条目具有依据，以及 Wayback 链接与精确捕获时间和原网址一致的要求。
- 保留旧内容 ID、新闻快照及永久一键启动入口；没有引入运行时抓取或新的依赖。

## 0.4.0 — 2026-10-07

- 实际采集并保存 2,243 条新闻，涵盖五种语言及 2004～2026 年；既有 32 条新闻 ID 全部保留，便于继续恢复收藏与足迹。
- 新闻库接入 Global Voices 的英语、中文、日语、法语、西班牙语接口，以及 NASA、European Central Bank，共 7 个接口、3 个发布主体；默认浏览项目内快照，浏览器不直接请求 RSS。
- 移除新闻 7 天有效期和 Surprise Me 的 48 小时来源门槛。可靠且不在未来的历史新闻可选择与恢复；7 天改为历史新闻标记阈值，48 小时保留为采集状态提示。
- 新闻刷新合并积累旧库，保留稳定身份并去重；合法空源和单源失败不清空已有报道，记录本次状态及上次成功采集时间。
- 增加按年有界历史补采 `npm run data:backfill -- --from=2004 --to=2026 --pages=2`，可通过 `--source` 单源重采；本轮每年最多 2 页，参数允许 1～10 页，不承诺全量。
- 保留原始发表日期、作者、译者、许可与已核验的原版链接；卡片明确历史新闻，收藏及备份继续保留相关字段，导入收藏仍不会扩充新闻池。
- About 与 News Drift 按实际采集状态动态显示来源和语言；历史新闻保持新闻类型，Time Machine 的人工年份切片及一键启动约定不变。

## 0.3.0 — 2026-10-04

- Surprise Me 每次从首页重新出发，提供关联窗口的悬停／按压反馈及到达提示；换站不移除操作按钮，保留键盘焦点。
- 手机固定上一站、下一站和收藏操作栏，考虑安全区域与内容遮挡；换站后在需要时滚动到新结果。
- 每个浏览器历史条目保存实际结果，前进／后退和刷新恢复对应页面；上一站能恢复完整时光卡片组，旧版最近遇见存储继续兼容。

- News Drift 增加报刊刊头、明确的来源所在地和长标题排版；保留日期、作者与许可。
- Time Machine 通过年代配置改变字体、按钮、浏览器外框和入场节奏，并标记事件／去处／存档切片。
- 新增配置驱动的年代注册表，去除年份条件；统一 ContentProvider 接口与静态适配器，支持校验、加载取消和失败重试。数据源切换和失败不丢弃临时收藏。
- 增加提供层与年代逻辑、浏览器返回、整组恢复、固定操作栏、焦点与来源切换集成测试；更新扩展文档和完整项目包。

## 0.2.0 — 2026-10-03

可在本地持续运行的静态 UI Demo；真实接口联调与公开部署留待后续。

- 重做主页与漫游界面：暖白纸面、橙色主动作、可交互的未知网页窗口，以及 Elsewhere／News Drift／Time Machine 各自的视觉语言。
- 增加可复用 BrowserFrame 与主题注册表；1999 使用灰色立体边框与蓝标题栏，2007 使用浅蓝玻璃渐变，2012 使用扁平浅灰与橙色。
- 拆分内容运行模式、纯选择算法、漫游 hook、页面局部样式与动效，支持移动端、可见键盘焦点及减少动画偏好。
- 默认 Demo 使用静态样本生成时间作为漫游参考，新闻明确标注样本且保留真实发表时间；`VITE_CONTENT_MODE=live` 可恢复按实时钟判断新鲜度，不自动请求接口。
- 完成本机收藏、取消收藏、移除、JSON 导出／导入；最多 500 条与 1 MiB，按稳定 ID 合并去重，同 ID 保留已有数据。
- 收藏保留原内容和必要署名；过期新闻作为个人旧快照查看，不重新进入漫游池。存储不可用时提示临时保存，损坏的旧数据不会自动覆写。
- 修复直接修改 URL hash 时可能保留上一模式内容的问题，保证当前模式与年代、结果卡片一致。
- 默认发布工作流改为静态 Demo，新闻更新仅手动启用；移除定时采集与自动快照提交。
- 更新本地安装、开发、构建、预览、内容模式与项目交接文档。已有 RSS adapter、来源记录和发布工作流保留，运行 Demo 无需真实 API、数据库或 Archive 联调。
