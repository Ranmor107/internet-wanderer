# Changelog

## 0.4.0 — 2026-10-07

- 实际采集并保存 2,243 条新闻，涵盖五种语言及 2004～2026 年；既有 32 条新闻 ID 全部保留，便于继续恢复收藏与足迹。
- 新闻库接入 Global Voices 的英语、中文、日语、法语、西班牙语接口，以及 NASA、European Central Bank，共 7 个接口、3 个发布主体；默认浏览项目内快照，浏览器不直接请求 RSS。
- 移除新闻 7 天有效期和 Surprise Me 的 48 小时来源门槛。可靠且不在未来的历史新闻可选择与恢复；7 天改为历史新闻标记阈值，48 小时保留为采集状态提示。
- 新闻刷新合并积累旧库，保留稳定身份并去重；合法空源和单源失败不清空已有报道，记录本次状态及上次成功采集时间。
- 增加按年有界历史补采 `npm run data:backfill -- --from=2004 --to=2026 --pages=2`，可通过 `--source` 单源重采；本轮每年最多 2 页，参数允许 1～10 页，不承诺全量。
- 保留原始发表日期、作者、译者、许可与已核验的原版链接；卡片明确历史新闻，收藏及备份继续保留相关字段，导入收藏仍不会扩充新闻池。
- About 与 News Drift 按实际采集状态动态显示来源和语言；历史新闻保持新闻类型，Time Machine 的人工年份切片及一键启动约定不变。

## 0.3.1 — 2026-10-06

- 新增数字敦煌、故宮典藏資料檢索、中国科普博览、文化遺産オンライン、地理院地図与 Museo Reina Sofía 馆藏，网站池从 30 个扩展为 36 个。
- 保留中文原创介绍，记录官网核验依据、主要语言、发布机构所在地及访问限制；统一只链接原站，不转载第三方正文或图片。
- 新增繁体中文显示名及非英语卡片、链接、收藏刷新恢复的浏览器回归。
- 修正浏览器测试的 Windows 路径校验，截图写入项目内测试目录；保留固定 Windows 一键启动入口与启动回归。
- Vite 不再监听 `.launcher/` 缓存与临时浏览器文件，避免 Windows 文件锁错误。

## 0.3.0 — 2026-10-04

完成漫游交互、模式差异和扩展结构三项开发，仍以静态 Demo 为默认。

- Surprise Me 每次从首页重新出发，提供关联窗口的悬停／按压反馈及到达提示；换站不移除操作按钮，保留键盘焦点。
- 手机固定上一站、下一站和收藏操作栏，考虑安全区域与内容遮挡；换站后在需要时滚动到新结果。
- 每个浏览器历史条目保存实际结果，前进／后退和刷新恢复对应页面；上一站能恢复完整时光卡片组，旧版最近遇见存储继续兼容。
- Elsewhere 增加三种手工明信片，历史网页退出该模式并归入 Time Machine。
- News Drift 增加报刊刊头、明确的来源所在地和长标题排版；保留日期、作者与许可。
- Time Machine 通过年代配置改变字体、按钮、浏览器外框和入场节奏，并标记事件／去处／存档切片。
- 新增配置驱动的年代注册表，去除年份条件；统一 ContentProvider 接口与静态适配器，支持校验、加载取消和失败重试。数据源切换和失败不丢弃临时收藏。
- 增加提供层与年代逻辑、浏览器返回、整组恢复、固定操作栏、焦点与来源切换集成测试；更新扩展文档和完整项目包。

## 0.2.0 — 2026-10-03

可在本地持续运行的静态 UI Demo；真实接口联调与公开部署留待后续。

- 重做主页与漫游界面：暖白纸面、橙色主动作、可交互的未知网页窗口，以及 Elsewhere／News Drift／Time Machine 各自的视觉语言。
- 增加可复用 BrowserFrame 与主题注册表；1999 使用灰色立体边框与蓝标题栏，2007 使用浅蓝玻璃渐变，2012 使用扁平浅灰与橙色。
- 拆分内容运行模式、纯选择算法、漫游 hook、页面局部样式与动效，支持移动端、可见键盘焦点及减少动画偏好。
- 默认 Demo 使用静态样本生成时间作为漫游参考，新闻明确标注样本且保留真实发表时间；`VITE_CONTENT_MODE=live` 可恢复按实时钟判断新鲜度，不自动请求接口。
- 完成本机收藏、取消收藏、移除、JSON 导出／导入；最多 500 条与 1 MiB，按稳定 ID 合并去重，同 ID 保留已有数据。
- 收藏保留原内容和必要署名；过期新闻作为个人旧快照查看，不重新进入漫游池。存储不可用时提示临时保存，损坏的旧数据不会自动覆写。
- 修复直接修改 URL hash 时可能保留上一模式内容的问题，保证当前模式与年代、结果卡片一致。
- 默认发布工作流改为静态 Demo，新闻更新仅手动启用；移除定时采集与自动快照提交。
- 更新本地安装、开发、构建、预览、内容模式与项目交接文档。已有 RSS adapter、来源记录和发布工作流保留，运行 Demo 无需真实 API、数据库或 Archive 联调。

## 0.1.0 — 2026-10-02

首次可运行的静态实现，尚未公开部署。

- 增加 Home、统一 Wander 与 About 三个视图，提供 Elsewhere、News Drift、Time Machine 和 Surprise Me 四个入口。
- 收录 30 个精选网站，以及 1999、2007、2012 各 6 条历史内容；三个精确 Wayback 快照保留真实捕获时间和原网址。
- 增加下一站、上一站、最多 20 条本机最近遇见、刷新恢复与清空足迹；存储不可用时继续本次漫游。
- 增加按池、来源及年份的随机选择、近期去重、小池放宽和空状态；年份包最多展示三张内容卡。
- 接入 Global Voices、NASA、European Central Bank 的 RSS 静态快照，首次采集保存 32 条真实资讯；保留发表时间、来源地区及必要作者／许可证署名。
- 增加来源超过 48 小时未更新与文章超过 7 天的过滤规则，以及单来源失败保留上次数据的处理。
- 增加原创中文介绍、来源说明、历史依据记录、响应式布局、键盘焦点和减少动画支持。
- 增加统一数据校验、离线逻辑测试、生产构建浏览器测试与 GitHub Pages 发布／每 12 小时更新工作流。
- 补充本地开发、内容维护、来源政策与部署文档；远程工作流执行和公开站点验收待部署后完成。
