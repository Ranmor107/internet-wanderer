# Internet Wanderer · UI direction

当前设计以 **A field guide to getting lost** 为主线。完整分析、参考入口和验收约定见 [UI_REDESIGN.md](docs/UI_REDESIGN.md)。

## 统一品牌

暖白纸面、深墨文字、朱红出发路径。细连接线、空心节点、轨道标记和坐标式编号贯穿首页与三种体验。系统无衬线用于正文、Georgia 用于感性标题、等宽字体用于地址与时间；不加载在线字体。留白、层次和可操作的视觉隐喻优先于粒子、霓虹或背景特效。

## 首页

大标题与 Surprise Me 构成主要出发点，旁边是三个相连的原创探索世界：网站节点、信号圆环、历史窗口。每个世界直接进入对应模式；手机保留首屏 CTA，地图改为纵向画卷。下方的短索引说明三个方向，不要求先设置偏好。

## 三种交互

| 模式 | 空间与操作 | 内容边界 |
| --- | --- | --- |
| Elsewhere | 真实最近遇见形成节点图，显示最近八个网站节点，全部足迹最多二十条；点击回访，Wander 延伸路径 | 仅表示在本站遇见，不追踪外站浏览 |
| News Drift | 深蓝接收台、原生来源频率尺、一次一篇的留白阅读区；拖动 / 点击 / 方向键调频，继续漂流随机换消息 | 刻度对应现有可用来源；地区是来源所在地，保留原始日期及署名，不声称实时广播 |
| Time Machine | 七个年份的时间轨道、相邻 / 随机年份、层叠事件 / 去处 / 档案窗口；斜面等宽、玻璃圆角和平面主题随年代变化 | 年代外观是设计演绎；真实事件与档案有依据入口，捕获时间与事件日期分别显示 |

Surprise Me 继续按可用池随机抽取，采用实际结果所属空间，标明当前旅程并提供进入完整模式的入口。

## 结构与交互约定

内容与纯随机算法、浏览器存储、年代注册、视觉组件和动效分离。NodeMap、SignalTuner、TimeRail 不包含采集或存储逻辑；默认数据和稳定 ID 保留。调频只对本次抽取缩小来源范围，不改变默认随机漂流。

动画只在路径延伸、节点落位、信号捕获和窗口切换时触发，不加入人为等待或无限循环。减少动画时直接展示新状态。按钮保留稳定焦点，移动端固定上一站 / 继续探索 / 收藏，外链在用户明确点击后以安全新标签页打开。收藏、备份、最近遇见及提供层容错继续可用。

开发与测试输出均留在项目内；每次交付必须通过生产构建与永久一键启动生命周期回归。
