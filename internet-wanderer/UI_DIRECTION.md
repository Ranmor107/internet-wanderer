# Internet Wanderer · UI direction

## 一台没有目的地的浏览器

核心句：**Get lost on the Internet again.**

把网站做成一张通往陌生互联网的登机口，而不是信息管理界面。暖白纸面、墨色文字、醒目的橙色出发按钮，搭配少量紫色和青柠。浏览器窗口、地址栏、游标与年代页签成为体验的一部分；不使用赛博黑底、数据图表或复古噪点堆叠。

## 首页与动作

- 首屏只有一个强动作：**Surprise Me / 随便去哪**。巨大标题与一个原创的、可以点开的未知网页窗口构成主视觉。
- Elsewhere、News Drift、Time Machine 是次级方向入口，不要求先配置偏好；不登录、不搜索即可出发。
- 结果页一次呈现一个偶遇；保留明确的“打开这一站”“下一站”和收藏。时光模式呈现同年的事件、去处与存档三个切片。
- 短暂的窗口入场、按钮按压与下一站切换建立“再点一次”的反馈，不加入人为加载等待。

## 三种气质

| 模式 | 视觉语言 | 强调色 |
| --- | --- | --- |
| Elsewhere | 手工互联网、贴纸、随意但克制的图形、陌生地址 | 青柠 / 墨绿 |
| News Drift | 剪报、报刊衬线标题、细横线、大留白；一次一条 | 淡紫 / 深紫 |
| Time Machine | 网页展览与时间刻度，字体、浏览器边框、控件与切换节奏随年代变化 | 1999 灰色立体边框＋蓝标题栏；2007 浅蓝玻璃渐变；2012 扁平浅灰＋橙色 |

字体采用本地系统无衬线作导航与正文、Georgia 衬线作感性标题、等宽字体作地址与年代，不依赖在线字体。颜色通过语义 token 和年代注册表集中管理。

## 实现与可访问性

内容仓库、纯选择算法、主题注册表、窗口组件、页面排版、动效样式相互独立。默认 Demo 使用静态内容和固定的样本时间，明确标注新闻为样本；未来可以替换数据提供层，不改视觉组件。外站仅在用户主动点击后打开。

移动端首先呈现标题和出发按钮，窗口缩为紧凑插画，方向入口纵向排列，结果与时间切片单列；漫游操作固定在底部，按需滚动到新结果。交互支持键盘、可见焦点、44px 触控目标、减少动态效果偏好；弹层保留焦点管理。动效只使用 transform / opacity，信息不依赖动画或颜色才能理解。
